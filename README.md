# PhotoPalette — AI 影像相片色卡產生器 產品規格書

---

## 1. 專案簡介 (Project Overview)

### 1.1 產品定位
PhotoPalette 是一款專為設計師、攝影師與創作者打造的單頁 Web 應用程式（SPA）。使用者上傳照片後，系統會自動分析影像中的核心色彩，並生成具備高質感比例與細節的專業色卡。

### 1.2 核心優勢
* **100% 本地隱私保護**：所有圖片與色彩運算皆於使用者瀏覽器完成，照片絕不傳輸至任何外部伺服器。
* **高質感編輯風格**：採用極簡優雅的暖白與暗藍調配色，凸顯相片與配色本身的視覺張力。
* **零延遲即時運算**：免去後端 API 傳輸，帶來順暢無縫的互動體驗。

## 2. 介面與版面配置 (UI/UX Layout)

系統採用**雙欄卡片式**響應式版面，在桌面端保持左右對比，行動端則自動切換為垂直單欄：

* **頂部導航欄 (Header)**
  * 品牌標誌與名稱 (`PhotoPalette Studio`)
  * 副標題標籤 (`Interactive Image & Color Card Generator`)
  * 主題切換按鈕 (淺色模式 / 深色模式)
  * 已儲存歷史記錄按鈕 (Saved)
  * 色卡匯出按鈕 (Export)

* **左側欄 (Left Column)**
  1. **照片上傳區 (Upload Photograph)**：
     * 支援點擊或拖曳上傳 (JPG, PNG, WebP，上限 15MB)。
     * **互動滴管模式**：點擊照片任一位置即可即時精確擷取該像素的顏色。
     * 照片元資料顯示 (檔名、解析度、檔案大小)。
  2. **色卡預覽區 (Palette Swatch Card Preview)**：
     * 展示高 48px ($h-12$) 的**動態色彩比例橫條**，懸停可查看該顏色的佔比與 HEX 碼。

* **右側欄 (Right Column)**
  1. **色彩辨識與風格設定 (Identified Color Cards)**：
     * **色卡數量切換**：可選擇 3 至 8 個配色標籤。
     * **背景過濾**：可自由勾選是否過濾極端純白與純黑的背景像素。
     * **融合式風格預設 (Style Presets)**：提供 8 種風格套用 (Natural, Soft Pastel, Morandi Muted, Vintage, Vibrant, Minimal, High Contrast, Monochromatic)。
  2. **3 欄式色卡網格 (3-Column Swatch Cards Grid)**：
     * 每張色卡清晰顯示 HEX 碼、中文/英文色名、覆蓋率百分比及色彩語意角色（Dominant, Secondary, Accent, Neutral）。
     * 提供「顏色鎖定 (Lock)」、「原生色彩調色盤」與「一鍵複製 (Copy HEX)」。

## 3. 核心功能說明 (Core Features)

| 功能模組 | 功能說明 |
| :--- | :--- |
| **自動色彩擷取** | 上傳照片後自動進行降採樣分析，並透過聚類演算法擷取最具代表性的配色方案。 |
| **即時滴管取色** | 開啟 Eyedropper 後，能在照片上移動並點擊取色，精確替換色卡中的顏色。 |
| **色彩鎖定與微調** | 鎖定特定喜愛的顏色後，切換風格或再生色卡時該顏色將保持不變。 |
| **文字對比度保護** | 色卡上的文字會根據底色亮度自動切換黑/白字，確保閱讀清晰度。 |
| **風格預設變換** | 在不破壞原圖色調前提下，進行飽和度與亮度的調和（如：粉彩、莫蘭迪、復古等）。 |

---

## 4. 匯出與 Persistence (Export & Storage)

* **多格式匯出**：
  1. **PNG 高解析度色卡圖牌**：自動合成包含照片與色卡的高畫質圖片供下載。
  2. **CSS 變數複製**：一鍵複製 `:root { --palette-color-1: #...; }` 供前端開發使用。
  3. **JSON 數據下載**：下載完整包含 RGB, HSL 與覆蓋率的結構化資料。
* **本地快取記錄**：
  * 使用者可儲存喜愛的配色方案至瀏覽器 LocalStorage，方便日後隨時查閱與複製。

---

## 5. 系統需求與相容性 (Requirements)

* **執行環境**：支援各大現代瀏覽器（Chrome, Edge, Safari, Firefox, iOS/Android 行動瀏覽器）。
* **效能承諾**：15MB 內之圖片，色彩分析與 UI 渲染於 1 秒之內完成。
